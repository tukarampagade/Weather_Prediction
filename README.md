# Weather Prediction Using Neural Network

A complete, end-to-end Diploma AI &amp; ML project that predicts whether it will rain
tomorrow using a **3-layer feedforward neural network implemented entirely from
scratch in NumPy** — no TensorFlow, Keras, or PyTorch anywhere in this codebase.

---

## 1. Project Overview

| | |
|---|---|
| **Task** | Binary classification — will it rain tomorrow? |
| **Model** | 3-layer feedforward NN (16 → 8 → 1), hand-coded forward/backward pass |
| **Optimizers** | SGD and Adam, both implemented from scratch |
| **Frameworks used** | NumPy, Pandas, Matplotlib, Seaborn, Scikit-learn (preprocessing/splitting only), Flask |
| **Frameworks NOT used** | TensorFlow, Keras, PyTorch |
| **Interface** | Flask web dashboard with a live prediction form |

## 3. Neural Network Architecture

```
Input (N features) → Hidden Layer 1 (16 neurons, ReLU)
                    → Hidden Layer 2 (8 neurons, ReLU)
                    → Output Layer  (1 neuron, Sigmoid)
```

- **Weight initialization:** He initialization for the two ReLU hidden layers,
  Xavier (Glorot) initialization for the Sigmoid output layer.
- **Loss function:** Binary Cross-Entropy (primary), Mean Squared Error (secondary
  comparison metric), both numerically stabilized with `np.clip`.
- **Backpropagation:** Manually derived gradients (`dZ`, `dW`, `db`) for every
  layer using the chain rule — see `neural_network.py` for the full derivation
  in code comments.

## 4. How to Run (Windows / PyCharm)

```bash
# 1. Create and activate a virtual environment
python -m venv venv
venv\Scripts\activate

# 2. Install dependencies
pip install -r requirements.txt

# 3. (Optional) Preview the preprocessing pipeline
python preprocess.py


# 4. Train the model — this regenerates model_weights.npz, scaler.pkl,
#    and all 7 graphs in static/graphs/
python train_model.py


# 5. Launch the web dashboard
python app.py

# 6. Open your browser
http://127.0.0.1:5000/
```
python -m venv venv
pip install -r requirements.txt
python preprocess.py
python train_model.py
python app.py
The repo already ships with a trained `model_weights.npz` and all 7 graphs
pre-generated, so `python app.py` works immediately — re-running
`train_model.py` is only needed if you want to retrain from scratch (e.g.
after editing the dataset or hyperparameters).

## 7. Notes on the Dataset

`weather.csv` is a **synthetically generated** dataset (2200+4000-style daily
records) built with realistic seasonal correlations between temperature,
humidity, pressure, wind speed, cloud cover, sunshine hours, and rainfall —
so that the relationships the neural network learns are meaningful and
demonstrable, rather than pure noise. Missing values are deliberately
injected into a few numeric columns to give `preprocess.py` real cleaning
work to do (mean/mode imputation), matching what a real-world weather
dataset (e.g. the Australian Rain dataset) would require.

See `services/weather_api.py` for a ready-made template showing how this
manual-entry form could later be replaced with a live OpenWeatherMap feed.

## 8. Troubleshooting

**`pip install` fails while building numpy from source (Windows, MSVC errors mentioning `npy_half` / `float16`):**
This happens when your Python version is newer than the numpy version can supply a
precompiled wheel for. `numpy>=2.3.0` (as pinned in `requirements.txt`) supports
Python 3.12–3.14, so make sure you're on a recent Python (3.11–3.14) and that
`requirements.txt` is not pinned to an old numpy version like `1.26.4`, which has
no Python 3.14 wheel. If it still fails, upgrade pip first:
`python -m pip install --upgrade pip`, then retry `pip install -r requirements.txt`.
