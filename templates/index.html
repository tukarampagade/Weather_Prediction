    Project Architecture & Viva Presentation

    A six-slide walkthrough of the system, from problem statement to deployment.

    Slide 01 / 06

    Problem Statement

    Predicting rain is a binary classification problem: given today's atmospheric readings — temperature, humidity, pressure, wind speed and cloud cover — decide whether tomorrow will bring rain. Relationships between these variables are non-linear, which makes a small neural network a natural fit over a simple linear rule.

    Slide 02 / 06

    Dataset & Preprocessing

    • Cleaning — handling missing or inconsistent atmospheric readings.
    • Feature engineering — deriving auxiliary fields such as sunshine hours and rainfall estimates.
    • Scaling — standardizing every feature so no single column dominates training.
    • Train / test split — holding out unseen rows to evaluate generalization honestly.
    Slide 03 / 06

    Neural Network Architecture

    Input ↓ Hidden Layer ↓ ReLU ↓ Output Layer ↓ Sigmoid ↓ Rain Probability
    Slide 04 / 06

    Forward & Backpropagation

    • Forward pass — inputs move through matrix multiplications and activations to a probability.
    • Loss — Binary Cross-Entropy measures how far that probability is from the true label.
    • Backward pass — the chain rule propagates the error backward to every weight.
    • Update — each weight shifts against its gradient to reduce the loss next time.
    Slide 05 / 06

    Adam Optimizer

    • Tracks a moving average of the gradient (first moment, m) for momentum.
    • Tracks a moving average of the squared gradient (second moment, v) for scale.
    • Applies bias correction so early updates aren't skewed toward zero.
    • Produces an adaptive learning rate per parameter, converging faster than plain SGD.
    Slide 06 / 06

    Evaluation & Deployment

    • Evaluation — Accuracy, Precision, Recall, F1 and a confusion matrix on the test set.
    • Deployment — the trained weights and scaler are loaded once at Flask startup.
    • Inference — every request on this page runs a fresh NumPy forward pass, no framework involved.
